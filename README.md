# OpenWrt Companion

![Version](https://img.shields.io/badge/version-1.2.1-blue) ![Platform](https://img.shields.io/badge/platform-Windows%20x64-lightgrey) ![License](https://img.shields.io/badge/license-CC%20BY--NC%204.0-orange)

Компактный настольный компаньон для роутера **OpenWrt**: живая панель «кто в сети и как живёт роутер» + анимированная иконка в трее. Без облака, без веб-интерфейса — всё напрямую с вашего роутера.

Окно 430×700 px, режим поверх всех окон, скрытие в трей — висит в уголке экрана и показывает сеть в реальном времени.

## ✨ Возможности

### Мониторинг
- **Плитки статистики**: время работы, скорость интернета ↓/↑ со спарклайном, ОЗУ, температура (все thermal-зоны + hwmon, берётся самая горячая)
- **Список устройств** в реальном времени: IP, имя, тип (ПК/телефон/ТВ/IoT), Wi-Fi сигнал, скорость каждого клиента ↓/↑
- **Табы**: Активные / Wi-Fi / LAN / Заблокированные / Архив
- **Трей-иконка с анимацией**: 4 полоски по уровню трафика, зелёная/красная вспышка при подключении/отключении устройств, меню топ-10 устройств с их скоростями + перезагрузка Wi-Fi/роутера прямо из трея
- **Уведомления Windows**: устройство подключилось/отключилось, роутер недоступен

### Интерфейс
- **Два языка — русский и английский**: переключатель в настройках, выбор сохраняется; переводится всё, включая трей-меню
- **Тёмная и светлая темы**: переключение в настройках, применяется мгновенно
- **Двуязычный инсталлятор**: язык выбирается при установке
- Блок «О программе»: версия, лицензия, ссылка на страницу проекта

### Управление
- Переименование устройств (алиасы), закрепление 📌, ручной выбор типа иконки
- ⏏ **Отключение клиента от Wi-Fi** (deauth) и 🚫 **блокировка через firewall** (правило по MAC)
- Перезагрузка радиомодуля (2.4/5 ГГц по отдельности) или всего роутера
- Смена канала Wi-Fi в один клик

### Скан эфира
- Список соседних сетей с сигналом и защитой, подсветка совпадающих/перекрывающихся каналов
- Вердикт по вашему каналу (занят / перекрывается / чист) и **рекомендация свободнее**
- Полный набор 5 ГГц каналов, включая **DFS** (52–64, 100–140) с пометками и подсказкой про CAC (~1 мин проверки радара)
- Корректный расчёт перекрытий для ширины каналов 20/40/80/160 МГц

### Диагностика и обслуживание
- Пинг шлюза / 8.8.8.8, журнал `logread`, память и диск
- **Бэкап конфига** (`sysupgrade -b`) в tar.gz одним кликом → папка Downloads
- Диагностика «ограниченного режима» с автоисправлением ACL (пишет `/usr/share/rpcd/acl.d/` за вас)

### Безопасность
- Пароль роутера хранится локально, зашифрованный **Windows DPAPI** (привязан к вашему аккаунту)
- **Пин SSH-ключа хоста**: отпечаток ключа роутера запоминается при первом подключении и проверяется при всех следующих; смена ключа (перепрошивка/перехват) блокирует подключение. Кнопка «Забыть ключ SSH» — для перепрошивки
- Ноль облака: приложение общается только с вашим роутером

### Мультироутер
- Несколько профилей (дом / дача / …): переключение в два клика, у каждого своё имя, хост, логин и пароль

## 🚀 Установка

1. Скачайте `OpenWrt Companion_1.2.1_x64-setup.exe` со страницы [Releases](../../releases)
2. Выберите язык инсталлятора (русский / english) и установите — при первом запуске откроются настройки
3. Введите адрес роутера, логин и пароль → «Проверить»

### Требования к роутеру
- OpenWrt с установленным **LuCI** (приложение использует его RPC-эндпоинт `/ubus`)
- Пользователь с правами на ubus-группы `luci` (обычно root)
- Для расширенных данных (сигнал клиентов, скан эфира, LAN-скорости) — доступ к `iwinfo`; если ACL его не даёт, приложение покажет баннер и предложит **автоисправление** одной кнопкой
- Для SSH-функций (диагностика, бэкап, исправление ACL) — включённый dropbear со входом по паролю

```bash

```

## 🧩 Как это работает

| Канал | Что берёт |
|---|---|
| **ubus через LuCI RPC** (`/ubus`, JSON-RPC) | устройства Wi-Fi, интерфейсы, WAN-счётчики, ARP, DHCP, uci, system board/info, iwinfo |
| **SSH** (russh, пароль + пин ключа) | диагностика, бэкап `sysupgrade -b`, автоисправление ACL |

Опрос фоновый (по умолчанию каждые 5 с, настраивается 2–30 с); скорости считаются дифференциалом счётчиков между опросами.

**Стек:** [Tauri 2](https://v2.tauri.app/) (Rust) + React + TypeScript, russh, DPAPI, двуязычный NSIS-инсталлятор. Релиз-сборка ~3,7 МБ, RAM ~50 МБ.

## 🔒 Замечание о безопасности

Приложение предназначено для **своего роутера в домашней сети**. Пароль хранится шифрованным (DPAPI), SSH-ключ хоста пинится, но: не выставляйте LuCI RPC и SSH на WAN, используйте сильный пароль root.
